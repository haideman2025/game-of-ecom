luoi-muc-tieu-builder
Lưới Mục Tiêu

PHASE 2 · EXPERIMENT
content-vo-han-engine
Content Matrix Vô Hạn
Mỗi leaf × format × hook angle = idea. Sinh 300-1000 idea, tỷ lệ 60% viral / 40% brand. Kho idea tái sử dụng vô hạn.

content-matrix.json

Data contracts
5 JSON artifacts mới
Mỗi sub-skill emit 1 JSON. Tất cả gom thành master.json — đây là contract chính để tất cả skill khác consume. Lưu D1 table mới: viral_grid_sessions.
🌳
keyword-tree.json
4-level tree: root → pillars → branches → leaves. Foundation of all content.
{ "root": "men's care", "pillars": [ { "name": "Hygiene", "branches": [...] }, { "name": "Health", "branches": [...] }, ... ], "leaves_count": 35, "type": "ket_hop" }
📊
content-matrix.json
300-1000 ideas, each tagged with leaf + format + hook angle + viral/brand ratio.
{ "total": 487, "viral_ratio": 60, "brand_ratio": 40, "ideas": [ { "leaf": "bot-ve-sinh-nam", "format": "carousel", "hook": "curiosity_gap", "tier": "viral", "title": "..." }, ... ] }
🎨
visual-dna.json
9 design elements + signature pattern. Used by image gen + LP + packaging.
{ "palette": ["#1A2240","#F59E0B",...], "typography": {"display":"Bowlby","body":"Inter"}, "composition": "rule_of_thirds", "motion": "smooth_ease_out", "mascot": {...}, "texture": "matte_paper", "light": "soft_directional", "iconography": "stroke_2px_rounded", "sound": "ambient_lofi", "signature": "diagonal_orange_strip" }
📅
execution-plan.json
30-day calendar + 70 hook bank + 14 KPI + 3 SOP for team handoff.
{ "calendar": [ {"day":1,"slot":"09:00","idea_id":"...","format":"reel"}, ... ], "hooks": [...70 hooks...], "kpis": [ {"name":"reach","baseline":1000,"target":10000}, ...14 KPIs... ], "sops": ["capture","produce","publish"] }
🌟
master.json (parent)
Gom tất cả 4 outputs + brand intake + metadata. Đây là contract chính truyền cho mọi downstream skill.
{ "version": "1.0.0", "brand": {...}, "phase_1_keyword_tree": { ... }, "phase_2_content_matrix": { ... }, "phase_3_visual_dna": { ... }, "phase_4_execution_plan": { ... }, "meta": { "total_leaves": 35, "total_ideas": 487, "viral_ratio": 60, "calendar_days": 30, "hook_count": 70, "kpi_count": 14 } }
